# Веб-приложение для автосалона

Веб-приложение для автосалона с каталогом автомобилей, системой регистрации пользователей и записью на тест-драйв. Разработано в рамках курсовой работы по дисциплине «Веб-программирование».

## Стек технологий

- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Backend:** PHP
- **База данных:** MySQL
- **Сервер:** Apache

## Функциональность

### Для покупателей
- Просмотр каталога автомобилей
- Поиск по марке и модели в реальном времени
- Просмотр подробной информации об автомобиле
- Регистрация и вход в систему
- Запись на тест-драйв

### Для администратора
- Добавление, редактирование и удаление автомобилей
- Загрузка фотографий автомобилей
- Просмотр заявок на тест-драйв
- Изменение статуса заявок

## Структура базы данных

**users** — пользователи системы (id, login, password, email, name, surname, phone, role)

**cars** — каталог автомобилей (id, brand, model, year, mileage, price, description, photo, created_at)

**requests** — заявки на тест-драйв (id, user_id, car_id, test_date, status, created_at)

## Установка и запуск

### Требования
- PHP 7.4+
- MySQL 5.7+
- Apache с поддержкой mod_rewrite

### Шаги

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/autoservice.git
```

2. Создайте базу данных MySQL и импортируйте дамп:
```bash
mysql -u root -p autoservice < autoservice.sql
```

3. Настройте подключение к БД в файле `includes/db.php`:
```php
$dsn = 'mysql:host=localhost;port=3306;dbname=autoservice;charset=utf8mb4';
$user = 'ваш_пользователь';
$pass = 'ваш_пароль';
```

4. Поместите файлы проекта в директорию веб-сервера и откройте в браузере.

## Безопасность

- Пароли хранятся в виде хэша (password_hash / password_verify)
- Запросы к БД выполняются через подготовленные выражения PDO
- Доступ к административной панели защищён проверкой роли пользователя
- Передача данных осуществляется по протоколу HTTPS
